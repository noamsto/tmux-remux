# tmux 3.8 Triggers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make tmux-remux render its own tmux.conf fragment from Go, gated on the detected tmux version, so tmux 3.8's event payloads stop silently dropping session ids from close events and the 60s save timer moves inside the tmux server.

**Architecture:** A new pure package `internal/triggers` is the single source of truth for every hook, bind and option tmux-remux installs. `tmux-remux triggers` prints its output; `tmux-remux.tmux` pipes that into `tmux source-file -`; `examples/tmux.conf` is a checked-in copy verified by a golden test. `internal/tmux` gains a version parser so the renderer can pick between a frozen pre-3.8 fragment and a 3.8 fragment.

**Tech Stack:** Go 1.25, kong (CLI), go-cmp (test diffs), real-tmux integration tests behind the `integration` build tag, bash + shellcheck for the TPM entry point.

**Spec:** `docs/superpowers/specs/2026-08-10-tmux-3.8-triggers-design.md`

## Background you need

Read the spec's "Verified tmux behavior" section before starting. The three facts that drive every task:

1. On tmux 3.8 `#{hook_session}` and `#{hook_session_name}` expand **empty** inside `pane-exited` — the event payload sets only `pane`, `window` and exit status. The event *target* is correct, so `#{session_id}` / `#{session_name}` work.
2. `after-kill-pane` carries no pane id on any version. The survivor-diff in `closeevent.resolveKilledPane` stays. Do not delete it.
3. `#{t:%M}` does not work. Only `#{T:@option}` reaches strftime, so the monitor's format string must live in a tmux option.

Two mechanics worth knowing before you write the integration tests:

- `run-shell` jobs inherit `TMUX=<socket>,<pid>,<session>`, so a tmux-remux binary invoked from a hook targets the test's socket automatically (`withSynthesizedTmuxEnv` in `internal/tmux/client.go` leaves an existing `TMUX` alone). Verified.
- Storage paths come from `XDG_DATA_HOME` (`internal/config/config.go:56`). `t.Setenv` in the test process propagates to the tmux server it spawns, and from there to hook jobs.

```go
package tmux

import (
	"context"
	"fmt"
	"regexp"
	"strconv"
	"strings"
)

// Version is a tmux release identified by major and minor number. Suffix
// letters (3.5a) and the "next-" prefix on development builds are dropped: a
// next-3.8 build carries the 3.8 feature set, which is what callers gate on.
type Version struct {
	Major int
	Minor int
}

func (v Version) String() string { return fmt.Sprintf("%d.%d", v.Major, v.Minor) }

// AtLeast reports whether v is major.minor or newer.
func (v Version) AtLeast(major, minor int) bool {
	if v.Major != major {
		return v.Major > major
	}
	return v.Minor >= minor
}

var versionRe = regexp.MustCompile(`([0-9]+)\.([0-9]+)`)

// ParseVersion reads a `tmux -V` line ("tmux 3.5a", "tmux next-3.8") or a bare
// "3.8" and returns the release it names.
func ParseVersion(s string) (Version, error) {
	s = strings.TrimSpace(s)
	m := versionRe.FindStringSubmatch(s)
	if m == nil {
		return Version{}, fmt.Errorf("tmux: unrecognized version %q", s)
	}
	major, err := strconv.Atoi(m[1])
	if err != nil {
		return Version{}, fmt.Errorf("tmux: unrecognized version %q", s)
	}
	minor, err := strconv.Atoi(m[2])
	if err != nil {
		return Version{}, fmt.Errorf("tmux: unrecognized version %q", s)
	}
	return Version{Major: major, Minor: minor}, nil
}

// Version runs `tmux -V` and parses the result.
func (c *Client) Version(ctx context.Context) (Version, error) {
	out, err := c.Run(ctx, []string{"-V"})
	if err != nil {
		return Version{}, err
	}
	return ParseVersion(out)
}
```

Create `internal/triggers/triggers.go`. The fragment chunks are raw strings holding `@BIN@` where the binary path goes; `Render` does one `strings.ReplaceAll` at the end. A sentinel rather than `fmt.Sprintf` is deliberate — the fragment is full of literal `%` (`-w 90%`, `'%M'`) that format verbs would swallow.

```go
// Package triggers renders the tmux.conf fragment that wires tmux-remux into a
// tmux server. It is the single source of truth for every hook, bind and option
// tmux-remux installs: tmux-remux.tmux pipes Render's output into
// `tmux source-file -`, and examples/tmux.conf is a generated copy of it.
//
// tmux 3.8 replaced notifications with events carrying key/value payloads, so
// a hook sees #{hook_<key>} only for keys its event set. That changes which
// format strings are correct, which is why Render takes a version.
package triggers

import (
	"regexp"
	"strings"

	"github.com/noamsto/tmux-remux/internal/tmux"
)

// Params configures a render.
type Params struct {
	// Bin is the tmux-remux path the hooks invoke.
	Bin string
	// Version is the tmux the fragment targets.
	Version tmux.Version
	// AutoRestore emits the restore --auto line.
	AutoRestore bool
}

const binToken = "@BIN@"

// bareBin matches paths needing no shell quoting inside a hook command.
var bareBin = regexp.MustCompile(`^[A-Za-z0-9._/-]+$`)

// quoteBin makes bin survive as one shell word inside a hook command string.
// tmux config quoting has no backslash escape, so a literal quote is spliced
// with '\'' — which closes the hook's own single-quoted argument, emits a
// quote, and reopens it. Paths needing no quoting are left bare so the
// generated examples/tmux.conf stays readable.
func quoteBin(bin string) string {
	if bareBin.MatchString(bin) {
		return bin
	}
	return `'\''` + bin + `'\''`
}

const headerLegacy = `# tmux-remux wiring — generated by ` + "`tmux-remux triggers`" + `; do not edit by hand.
# Targets tmux < 3.8.

`

const saveHooks = `# Save snapshots on structural change
# after-split-window stands in for the pane-created hook tmux doesn't have: without it
# a new pane reaches no snapshot until the next window/session event, and undo can
# only restore what a snapshot recorded.
set-hook -g session-created     'run-shell -b "@BIN@ save --reason=hook:session-created"'
set-hook -g window-linked       'run-shell -b "@BIN@ save --reason=hook:window-linked"'
set-hook -g after-split-window  'run-shell -b "@BIN@ save --reason=hook:after-split-window"'
set-hook -g client-detached     'run-shell -b "@BIN@ save --reason=hook:client-detached"'

`

// closeHooksLegacy captures close events on tmux < 3.8, where pane-exited's
// hook_session and hook_session_name are populated.
const closeHooksLegacy = `# Capture close events for undo
# Hook pane-exited (pane-died only fires with remain-on-exit); kind stays "pane-died" for the diff
# --session-name is quoted so a session name containing spaces stays one shell
# word; the '\'' splices in a literal quote without ending this line's own
# single-quoted argument (tmux's config quoting has no backslash escape).
# --session needs the same treatment: #{hook_session} expands to a $-prefixed
# id like $38, which an unquoted sh -c reads as the positional parameter $3
# followed by a literal 8 — collapsing distinct session ids and confusing the
# cascade-close dedup in closeevent.Capture.
set-hook -g pane-exited        'run-shell -b "@BIN@ capture-event pane-died          --pane=#{hook_pane}    --window=#{hook_window} --session='\''#{hook_session}'\'' --session-name='\''#{hook_session_name}'\''"'
` + killPaneHook + windowSessionHooks

// killPaneHook is version-independent: no tmux release gives a command hook the
// pane it killed.
const killPaneHook = `# prefix+x kills the pane without its program exiting, so pane-exited never fires.
# after-kill-pane is a command hook with no hook_pane; the id is recovered by diffing
# the survivors against the last snapshot.
set-hook -g after-kill-pane    'run-shell -b "@BIN@ capture-event pane-died"'
`

// windowSessionHooks are version-independent: window-unlinked and
// session-closed carry session and session_name in their 3.8 payloads too.
const windowSessionHooks = `set-hook -g window-unlinked    'run-shell -b "@BIN@ capture-event window-unlinked    --window=#{hook_window} --session='\''#{hook_session}'\'' --session-name='\''#{hook_session_name}'\''"'
set-hook -g session-closed     'run-shell -b "@BIN@ capture-event session-closed     --session='\''#{hook_session}'\'' --session-name='\''#{hook_session_name}'\''"'

`

const autoRestore = `# Auto-restore on tmux start
run-shell -b '@BIN@ restore --auto'

`

const binds = `# Keybindings
bind   u    run-shell "@BIN@ undo --pop --session='#{session_name}'"
bind   U    display-popup -E -w 90% -h 85% "@BIN@ pick --kind=close --session='#{session_name}'"
bind   R    display-popup -E -w 90% -h 85% '@BIN@ pick --kind=snapshot'
bind C-s    run-shell '@BIN@ save --reason=keybinding'
`

// Render returns the tmux.conf fragment wiring tmux-remux into a tmux server.
func Render(p Params) string {
	var s strings.Builder
	s.WriteString(headerLegacy)
	s.WriteString(saveHooks)
	s.WriteString(closeHooksLegacy)
	if p.AutoRestore {
		s.WriteString(autoRestore)
	}
	s.WriteString(binds)
	return strings.ReplaceAll(s.String(), binToken, quoteBin(p.Bin))
}
```

const header38 = `# tmux-remux wiring — generated by ` + "`tmux-remux triggers`" + `; do not edit by hand.
# Targets tmux 3.8+.

`

// monitorSave replaces the external 60s save timer with a server-side monitor
// hook. #{t:%M} does NOT work: t: formats a time *variable*, not
// strftime-of-now. T: re-expands a variable's value through strftime, so the
// format string has to live in an option. The monitor evaluates once a second
// and fires when the value changes — once a minute.
//
// The hook is global, which matters: a global monitor is bound to no session,
// so it falls back to the lowest-id live session and keeps firing across
// session churn. It goes quiet only when no session exists, which is exactly
// when a timer save is a no-op.
const monitorSave = `# Periodic snapshot floor (tmux 3.8 monitor hook — replaces an external timer)
set -g @remux_save_tick '%M'
set-hook -g -B '@remux-save:session:#{T:@remux_save_tick}' 'run-shell -b "@BIN@ save --reason=timer"'

`

// closeHooks38 differs from the legacy fragment in one line. tmux 3.8's
// pane-exited payload sets pane, window and exit status but no session
// (server_fire_pane_exit), so #{hook_session} and #{hook_session_name} are
// empty there. The event target is correct, so read #{session_id} and
// #{session_name} instead. window-unlinked and session-closed keep hook_* —
// their payloads do carry the session.
const closeHooks38 = `# Capture close events for undo
# Hook pane-exited (pane-died only fires with remain-on-exit); kind stays "pane-died" for the diff
# --session and --session-name are quoted so a $-prefixed id or a name with
# spaces stays one shell word; the '\'' splices in a literal quote without
# ending this line's own single-quoted argument (tmux's config quoting has no
# backslash escape). An unquoted $38 would read as positional parameter $3
# followed by a literal 8, confusing the cascade dedup in closeevent.Capture.

// tmux-remux.tmux pipes it into `tmux source-file -`; examples/tmux.conf is a
// checked-in copy of the tmux 3.8 output.
type TriggersCmd struct {
	Bin         string `help:"tmux-remux path the hooks invoke (default: this binary)"`
	TmuxVersion string `name:"tmux-version" help:"target tmux version, e.g. 3.8 (default: detected via tmux -V)"`
	AutoRestore string `name:"auto-restore" default:"on" enum:"on,off" help:"emit the restore --auto line"`
}

func (c TriggersCmd) Run() error {
	bin := c.Bin
	if bin == "" {
		exe, err := os.Executable()
		if err != nil {
			return err
		}
		bin = exe
	}

	// A guessed version would be worse than none: a 3.8 fragment sourced by a
	// 3.7 tmux fails on set-hook -B partway through, leaving hooks half-wired.
	var (
		v   tmux.Version
		err error
	)
	if c.TmuxVersion != "" {
		v, err = tmux.ParseVersion(c.TmuxVersion)
	} else {
		v, err = tmux.NewClient("tmux").Version(context.Background())
	}
	if err != nil {
		return err
	}

	fmt.Print(triggers.Render(triggers.Params{
		Bin:         bin,
		Version:     v,
		AutoRestore: c.AutoRestore == "on",
	}))
	return nil
}

## Notes for the implementer

**Do not delete `closeevent.resolveKilledPane`.** Issue #62 proposed it; the probes disproved it. Task 7 guards the path.

**Do not hand-edit `examples/tmux.conf`.** It is generated. Change `internal/triggers/triggers.go` and run `go test ./internal/triggers/ -update`.

**The `%` characters in the fragment are load-bearing** — `-w 90%`, `'%M'`, `%S`. That is why the templates use an `@BIN@` sentinel with `strings.ReplaceAll` rather than `fmt.Sprintf`, which would need every literal `%` doubled. Do not "simplify" it back to `Sprintf`.

**Quoting has three levels.** The fragment is parsed by tmux's config parser, the hook value is re-parsed by tmux when the hook fires, and the `run-shell` string is parsed by `sh -c`. `'\''` is how a literal quote survives level one. Only the integration tests in Tasks 6-8 exercise all three; a golden test only proves level zero.
